This is the first post on my new personal site. I wanted a simple home for the things I learn and build, without the overhead of maintaining a custom stack just to publish a few paragraphs.

I plan to use this space for:

- notes from materials chemistry and machine learning
- implementation details and lessons from software projects
- shorter updates on the things I am building independently

The site is built with [Astro](https://astro.build/) and the [Dante theme](https://github.com/JustGoodUI/dante-astro-theme), then deployed to GitHub Pages. The source is available at [OthinusG/index](https://github.com/OthinusG/index).
