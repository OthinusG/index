This is the site you are reading now: a content-first personal notebook built with [Astro](https://astro.build/) and the [Dante theme](https://github.com/JustGoodUI/dante-astro-theme).

The project remains deliberately small:

- Markdown content collections for posts, pages, and projects
- Tailwind CSS for layout and styling
- A shared base-path helper so the site works at a GitHub Pages subpath
- GitHub Actions for build and deployment on every push to `main`

The source is available at [OthinusG/index](https://github.com/OthinusG/index).
