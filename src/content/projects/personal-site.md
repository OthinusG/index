This is the site you are reading now: a content-first personal notebook built with [Astro](https://astro.build/) and [Navfolio](https://github.com/dodolalorc/astro-navfolio).

The project remains deliberately small:

- Markdown and MDX content collections for posts, projects, and short notes
- Static full-text search with Pagefind
- A GitHub Pages project-site setup with automatic base-path handling
- GitHub Actions for build and deployment on every push to `main`

The source is available at [OthinusG/index](https://github.com/OthinusG/index).
