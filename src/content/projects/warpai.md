Warpai is a native desktop terminal for coordinating CLI agents across shared projects and Git worktrees. Work is organized around tasks and agent handoffs, while each worktree keeps concurrent changes isolated.

It is distributed as a macOS app through a Homebrew tap and GitHub releases.
